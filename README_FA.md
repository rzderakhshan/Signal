# Hyperliquid Whale Tracker v6

نسخه v6 علاوه بر چرخه کامل Signal ID، قیمت ورود هر نهنگ حاضر در MAIN SIGNAL را هم نمایش می‌دهد.

## Signal ID و چرخه معامله
سیگنال اصلی نمونه:

`MAIN-ETH-LONG-20261006-001`

سیگنال نهنگ منفرد نمونه:

`WHL-SOL-SHORT-20261006-002`

همان ID تا پایان سیگنال ثابت می‌ماند.

Telegram می‌تواند سه نوع پیام بدهد:
- `OPEN MAIN SIGNAL` / `OPEN WHALE SIGNAL`
- `UPDATE MAIN SIGNAL` / `UPDATE WHALE SIGNAL`
- `CLOSE MAIN SIGNAL` / `CLOSE WHALE SIGNAL`

در پیام CLOSE موارد زیر می‌آید:
- Signal ID
- Coin و جهت LONG/SHORT
- قیمت مرجع باز شدن
- قیمت بسته شدن
- نتیجه درصدی از زمان صدور سیگنال
- مدت باز بودن
- دلیل بسته شدن

برای MAIN SIGNAL بسته شدن زمانی رخ می‌دهد که Consensus دیگر شروط اصلی را نداشته باشد یا جهت اجماع برگردد.
برای WHALE SIGNAL بسته شدن زمانی ثبت می‌شود که همان نهنگ پوزیشن مربوطه را ببندد/برگرداند یا از Top-10 خارج شود.


## قیمت ورود نهنگ‌ها
در پیام `OPEN MAIN SIGNAL` این موارد جدا نمایش داده می‌شوند:
- `Signal Entry`: قیمت بازار هنگام صدور سیگنال
- `Average Whale Entry`: میانگین وزنی Entry نهنگ‌های هم‌جهت بر اساس اندازه پوزیشن
- `Whale entries`: Entry، اندازه پوزیشن، رتبه و Quality هر نهنگ حاضر در همان سیگنال

در `UPDATE MAIN SIGNAL` Entry فعلی هر نهنگ و Average Whale Entry جدید هم به‌روزرسانی می‌شود. در پیام `CLOSE MAIN SIGNAL` نیز Signal Entry و Average Whale Entry زمان باز شدن نگه داشته می‌شوند.

## Top-10 پویا
- هر 5 دقیقه مانیتور می‌شود.
- هر 6 ساعت Ranking دوباره ارزیابی می‌شود.
- نهنگ بهتر می‌تواند جای نهنگ ضعیف‌تر را بگیرد.
- امتیاز نهنگ از PnL اخیر، PnL ماهانه/کل، اندازه حساب، اندازه پوزیشن و ریسک ساخته می‌شود.

## Main Signal
MAIN فقط وقتی باز می‌شود که چند نهنگ قوی هم‌جهت باشند و شروط `MAIN_MIN_WHALES`, `MAIN_MIN_WEIGHTED_SHARE` و حداقل Notional برقرار باشد.

## State
تمام Signal IDها و وضعیت OPEN/CLOSED در `.state/whale_state.json` نگه‌داری می‌شوند و GitHub Actions آن را بین اجراها Cache می‌کند.

## منطق Limit Order در نسخه v7

این نسخه بین «سفارش منتظر» و «معامله‌ای که واقعاً اجرا شده» فرق می‌گذارد.

### 1) PENDING WHALE SIGNAL
وقتی یک نهنگ Top-10 یک Limit Order بزرگ و نسبتاً نزدیک به قیمت فعلی بگذارد، پیام Pending می‌آید.

- حداقل ارزش سفارش: `MIN_ORDER_USD` (پیش‌فرض 200,000 دلار)
- حداکثر فاصله سفارش جدید تا قیمت فعلی: `NEW_LIMIT_MAX_DISTANCE_PCT` (پیش‌فرض 1.5%)
- این پیام به معنی ورود قطعی نیست؛ سفارش هنوز در Order Book منتظر است.

### 2) LIMIT APPROACHING
ممکن است سفارش از قبل وجود داشته باشد و هنگام ایجاد خیلی دور بوده باشد. اگر بعداً قیمت به آن نزدیک شود، فقط یک بار پیام `LIMIT APPROACHING` می‌آید.

- آستانه پیش‌فرض نزدیکی: `APPROACH_DISTANCE_PCT = 0.5%`
- نزدیکی قیمت فقط احتمال فعال‌شدن را بیشتر می‌کند و زمان اجرا را تضمین نمی‌کند.

### 3) PENDING SIGNAL ACTIVATED
اگر همان Order ID در Fillهای جدید دیده شود، Pending Signal با همان ID به حالت Active تبدیل می‌شود.

- قیمت واقعی Fill نمایش داده می‌شود.
- اگر Fill حالت Taker/Crossed داشته باشد، `MARKET/TAKER` نشان داده می‌شود.
- اگر Maker باشد، `LIMIT/MAKER FILL` نمایش داده می‌شود.

### 4) MARKET / TAKER ENTRY
اگر نهنگ بدون Pending قبلی وارد شود و Fill حالت Taker داشته باشد، پیام ورود واقعی با توضیح فارسی می‌آید.
این یک معامله اجراشده است، نه سفارش منتظر.

### 5) WHALE LIMIT CLUSTER
اگر حداقل چند نهنگ در یک Coin و جهت یکسان Limit Orderهای بزرگ و نزدیک به قیمت فعلی داشته باشند، ربات آنها را جمع می‌کند و یک پیام Cluster می‌دهد.

پیام شامل:
- تعداد نهنگ‌ها
- تعداد سفارش‌ها
- محدوده قیمت سفارش‌ها
- مجموع ارزش سفارش‌ها
- قیمت فعلی

پیش‌فرض:
- فاصله از بازار برای Cluster: 1%
- حداقل 2 نهنگ
- حداقل مجموع سفارش‌ها: 500,000 دلار

### معنی پیام‌ها به فارسی
- `PENDING`: سفارش منتظر است و هنوز معامله باز نشده.
- `APPROACHING`: سفارش قدیمی/موجود حالا به قیمت بازار نزدیک شده.
- `ACTIVATED`: همان سفارش اجرا شده و معامله فعال شده.
- `MARKET/TAKER`: ورود اجراشده و فوری/تیکر بوده.
- `LIMIT CLUSTER`: چند نهنگ سفارش‌های نزدیک و هم‌جهت در یک محدوده دارند.
- `REMOVED`: سفارش دیگر باز نیست و Fill متناظر پیدا نشده؛ به عنوان Cancel/Removed در نظر گرفته می‌شود.

> این پیام‌ها صرفاً ردیابی رفتار نهنگ‌ها هستند و تضمین‌کننده نتیجه معامله یا زمان Fill شدن سفارش نیستند.
