# دیده‌بان یکپارچهٔ بازار: بنیادی + نوسان + هشدار

این پوشه برنامهٔ اصلی است. `stock finder` و `Stock_market` پروژه‌های مرجع بودند: ماژول‌های `legacy_fundamental.py` و `legacy_news.py` از منطق AEGIS همان پروژه‌های متعلق به شما جدا شده‌اند. پوشه‌های قدیمی، فایل‌های PDF، گزارش‌ها، محیط مجازی، `.env` و تاریخچهٔ Git آن‌ها جزو این بسته نیستند.

## برنامه چه می‌کند؟

هر بار برای نمادهای `watchlist.json` کندل‌های ۵ و ۱۵ دقیقه‌ای سهام را از Yahoo Finance و کریپتو را نخست از Kraken spot (در صورت خطا از Yahoo) دریافت می‌کند. کندل باز را کنار می‌گذارد، نوسان (ATR و دامنهٔ ۴۸ کندل)، جایگاه قیمت در محدوده و حجم نسبی را حساب می‌کند. واگرایی معمولی RSI با تأیید ۲ کندل و بازگشت **قیمت** به باند بولینگر را به‌عنوان هشدار بررسی تشخیص می‌دهد. سیگنال تکراری را بر اساس نماد، دلیل، تایم‌فریم و زمان کندل حذف می‌کند.

برای سهام، امتیاز بنیادی قدیمی AEGIS از رشد درآمد و سود، حاشیه‌ها، جریان نقد آزاد، نسبت بدهی، نسبت‌های ارزش‌گذاری و بازده سرمایه استفاده می‌کند و درصد **پوشش داده** را نیز نشان می‌دهد. اگر داده کافی نباشد، امتیاز ساختگی داده نمی‌شود. تیترهای خبری هفت روز اخیر فقط زمینهٔ خبری‌اند؛ شمارش یا کلیدواژهٔ خبر به‌تنهایی دستور خرید نیست. دادهٔ بنیادی تا ۲۴ ساعت در `research_cache.json` نگهداری می‌شود. برای کریپتو امتیاز بنیادی شرکت محاسبه نمی‌شود.

در ساعت‌های ۹، ۱۲، ۱۶ و ۲۰ به وقت برلین، وقتی دادهٔ تازه موجود باشد، گزارش کوتاه «سهام با کیفیت بنیادی و نوسان» و «کریپتو با نوسان» به تلگرام می‌رود. هشدار سیگنال تازه در سایر اجراها هم ارسال می‌شود. در حالت آزمایشی گزارش روی صفحه نمایش داده می‌شود. رتبهٔ گزارش، **احتمال سود یا سیگنال خرید** نیست.

## راه‌اندازی روی ویندوز

فقط فایل‌های این پوشه را در یک فولدر تمیز نگه دارید. ZIP قدیمی، `venv` و دو پوشهٔ پروژهٔ مرجع را در مخزن برنامه قرار ندهید. داخل فولدر برنامه در PowerShell اجرا کنید:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest -v
.\.venv\Scripts\python.exe scanner.py --dry-run
```

برای گزارش فوری آزمایشی: `python scanner.py --dry-run --report-now` (در `--dry-run` گزارش خودکار هم نمایش داده می‌شود). دریافت قیمت واقعی به اتصال اینترنت نیاز دارد. نبود سیگنال در یک اجرا طبیعی است؛ اما اگر هیچ نمادی داده نداشته باشد، برنامه با خطا خارج می‌شود.

## تلگرام

ربات را در کانال `Signal` مدیر کنید و مجوز ارسال پیام بدهید. `.env.example` را به `.env` کپی و فقط **در همان فایل محلی** مقدارها را بنویسید؛ `TELEGRAM_CHAT_ID` برای کانال عمومی می‌تواند `@username` کانال و برای کانال خصوصی شناسهٔ عددی آن باشد. تنظیمات چت پروژه‌های قدیمی عمداً خوانده نمی‌شوند تا پیام اشتباهی به کانال قبلی نرود.

```text
TELEGRAM_BOT_TOKEN=توکن_واقعی_ربات
TELEGRAM_CHAT_ID=@username_کانال_یا_شناسه_عددی
```

ابتدا `python scanner.py --test-telegram` را اجرا کنید تا فقط یک پیام اتصال ارسال شود؛ سپس `python scanner.py` برای یک اسکن و ارسال واقعی اجرا می‌شود. توکن را داخل چت، کد، گزارش یا Git قرار ندهید. در GitHub این دو مقدار را به‌عنوان Repository Secrets با نام‌های `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` تعریف کنید. فایل `.env` به‌صورت خودکار در Git نادیده گرفته می‌شود.

## اجرای زمان‌بندی‌شده

`.github/workflows/scan.yml` برای اجرای هر ۵ دقیقه آماده است. این فایل فقط وقتی در **ریشهٔ مخزن درست** قرار گیرد فعال می‌شود؛ GitHub ممکن است اجرای زمان‌بندی‌شده را با تأخیر انجام دهد. فایل‌های `state.json` و `research_cache.json` از طریق cache بین اجراها بازیابی می‌شوند. جلوگیری از تکرار در GitHub با cache بهترین تلاش است و در صورت حذف cache تضمین دائمی ندارد. اگر هشدارها باید دقیقاً سر وقت باشند، اجرای دائمی روی یک سرور با دیتای معتبر مناسب‌تر است.

## نمادها و حدود کاربرد

`watchlist.json` فعلاً شامل ۵ سهم و ۴ جفت کریپتو به‌عنوان **نمونه** است. در دسترس بودن هر ابزار، نام دقیق، ارز، ISIN و قیمت قابل معامله را در حساب Trade Republic خودتان بررسی کنید. این برنامه از حساب Trade Republic داده نمی‌گیرد؛ Yahoo Finance منبع قیمت سهام و دادهٔ بنیادی، و Kraken spot منبع اصلی قیمت کریپتو است و ممکن است با قیمت/اسپرد داخل اپ فرق داشته باشد. در این نسخه محصولات اهرمی با سهم پایه یکسان فرض نمی‌شوند و به‌صورت خودکار ارزیابی نمی‌شوند. به علت محدودیت منبع داده، حداکثر ۴۰ نماد در یک فهرست مجاز است.

اندیکاتور ارسالی `RSI [TORYS]` باند بولینگر را روی **RSI** دارد و علامت خروج RSI از باند را نشان می‌دهد. قانون بازگشت **قیمت** در این برنامه یک شرط مستقل و جدید است. واگرایی فقط زمان تأیید پیوت اعلام می‌شود. «کف یا سقف روز» در لحظه قابل تشخیص قطعی نیست؛ جایگاه گزارش، قیمت را در محدودهٔ ۴۸ کندل بسته‌شدهٔ گذشته نشان می‌دهد. نتایج قبل از معامله باید با دادهٔ تاریخی، اسپرد، هزینه و لغزش ارزیابی شوند.

## فایل‌ها

- `scanner.py`: دریافت داده، رتبه‌بندی نوسان، تشخیص سیگنال، گزارش و ارسال تلگرام.
- `research.py`: ذخیرهٔ روزانهٔ تحلیل بنیادی و زمینهٔ خبر.
- `legacy_fundamental.py`, `legacy_news.py`, `legacy_utils.py`: منطق جداشده از پروژه‌های قدیمی شما.
- `watchlist.json`: فهرست نمادها؛ `test_scanner.py`: آزمون‌های اصلی.
- `.env.example`: الگوی محلی بدون رمز؛ `.github/workflows/scan.yml`: زمان‌بندی آمادهٔ انتشار.
